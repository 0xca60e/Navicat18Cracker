# Navicat18Cracker

`Navicat18Cracker` is a patch and keygen tool that you can active Navicat version 18 offline.

## How does it work?
1. Add `127.0.0.1 activate.navicat.com` record to `hosts` file.
2. Replace RSA public key in `libcc.dll`.
3. Generate fake `SN`.
4. Generate fake activation code with new RSA private key.
